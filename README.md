# snake-robot-locomotion-simulation

This repository contains the modified simulation framework and source code for the paper: "Comparing Terrestrial and Aquatic Snake Robot Locomotion: Effects of Environmental Conditions and Actuation Parameters in a MAT-DiSMech Simulation". It builds upon the original MAT-DiSMech codebase by Lahoti & Jawed (2025), specifically branching from commit e999cbc, with custom adaptations for aquatic and land environments, and aquatic and land snake locomotion.
